# Shared UI Component Inventory

This file is the source-of-truth inventory for generalized UI components in
`@golem/ui`. Update it in the same change whenever a shared component is added,
renamed, removed, or materially changes purpose.

## Components

- `Alert` - Inline feedback banner for page or section-level messages.
- `Button` - Standard action button with variants and busy state.
- `Callout` - Contextual notice block for info, warning, or danger messages.
- `ConfirmDialog` - Generic confirmation modal composition.
- `DialogScaffold` - Standard dialog frame with title, close action, and body slots.
- `FormField` - Field label, helper text, and input wrappers.
- `Modal` - Low-level modal container.
- `NumberStepper` - Numeric input with increment/decrement controls.
- `PageHeader` - Standard page heading and actions layout.
- `Pagination` - Generic paginated navigation controls.
- `ReviewList` - Key/value review list for confirmation steps.
- `SelectableCard` - Clickable/selectable option card.
- `Skeleton` - Placeholder loading primitives, including table skeletons.
- `Spinner` - Compact inline progress indicator for controls.
- `StatusBadge` - Generic status label with tone and optional busy indicator.
- `StepProgress` - Multi-step progress indicator.
- `SummaryChip` - Compact summary item with optional icon.
- `Tabs` - Segmented tab navigation.
- `Toast` - Toast provider and hook for transient messages.
- `ToggleSwitch` - Binary toggle control.
- `cn` - Class-name joining helper.
