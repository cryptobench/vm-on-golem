VM on Golem lets requestors rent virtual machines from providers on the Golem Network. Requestors use a web app to discover capacity, open streaming payments, create VMs, and connect over SSH. Providers run software that publishes available capacity, verifies payments, provisions VMs, and exposes operational controls.

Start with the section that matches what you want to do.

## I want to rent a VM

Use the [requestor documentation](/docs/requestors) if you want to find providers, fund a wallet, rent a machine, connect to it, and manage active rentals.

This path focuses on the web app and the rental lifecycle. It avoids provider setup details unless they explain something visible to requestors.

## I want to host VMs

Use the [provider documentation](/docs/providers) if you want to make your machine available, set pricing, publish capacity, receive payments, monitor activity, and withdraw earnings.

This path focuses on Provider Desktop, the provider server, networking, pricing, payment verification, and operational health.

## I want technical details

Use [concepts](/docs/concepts) for shared background such as discovery, streaming payments, networking, SSH access, and security.

Use [reference](/docs/reference) for commands, APIs, configuration values, and local development workflows.
