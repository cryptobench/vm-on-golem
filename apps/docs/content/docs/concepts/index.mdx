Concepts explain the shared mechanics behind requestor and provider workflows. You do not need to read this section before using the product, but it helps when you want to understand why the flows behave the way they do.

## When to read concepts

Read concepts when a task guide mentions discovery, streams, provider endpoints, SSH proxying, wallet identity, or authorization and you want deeper context.

The role based guides remain the main path for using the product.

## What concepts cover

This section covers the system model, provider discovery, streaming payments, networking, SSH access, and the security boundaries between requestors, providers, wallets, and VMs.

## What concepts do not cover

Concept pages are not command references. Exact environment variables, CLI commands, API endpoints, and local development instructions live in [Reference](/docs/reference).
